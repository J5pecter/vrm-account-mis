# 08 · Data dictionary — schema v3 (Google Sheet tabs)

All cells are written as **text** (`@` format); timestamps are UTC ISO-8601; business dates are `YYYY-MM-DD` (IST business date).
IDs are UUIDv4. Columns are never reordered; new columns are appended. `setup()` refuses to touch a tab whose header differs.

## Meta
| Column | Description |
|---|---|
| key / value / updated_at | `schema_version` = `3` |

## VRMs
| Column | Description |
|---|---|
| id | Stable UUID; never changes on rename |
| canonical_name | Display name (NFKC, collapsed spaces) |
| name_key | Lower-case match key; unique across all VRMs |
| status | `active` \| `archived` |
| created_at, created_by, updated_at, updated_by | UTC time / user id (`setup` for seed) |

## Users
| Column | Description |
|---|---|
| id, name, name_key | Account; name is the sign-in name (unique by `name_key`) |
| role | `admin` \| `member` \| `reviewer` |
| assigned_vrm_id | Required for member; optional for admin; empty for reviewer |
| active | `true` \| `false` |
| pw_algo, salt, password_hash | `pbkdf2-sha256$1000`, random salt, HMAC(pepper, PBKDF2) hex — never returned by the API |
| must_change_password | `true` after provisioning/reset |
| failed_count, locked_until | Lockout state |
| created_at, created_by, updated_at, updated_by, password_changed_at, last_login_at | Lifecycle |

## Entries (activation records)
| Column | Description |
|---|---|
| id | Stable UUID (kept through corrections, deletes, restores) |
| vrm_id | FK → VRMs.id |
| activation_date | Business date |
| client_code_original | Code exactly as entered (trimmed), leading zeros kept |
| code_key | NFKC + upper-case key; **globally unique, including deleted rows** |
| status | `active` \| `deleted` |
| source | `manual` \| `import` |
| import_batch_id | FK → ImportBatches.id (imports) |
| request_id | Client request ID that created the row (crash recovery / idempotency) |
| created_at, created_by | Server time, user id |
| updated_at, updated_by | Last correction/restore |
| deleted_at, deleted_by, delete_reason | Soft-delete tombstone |

## Aliases
| Column | Description |
|---|---|
| alias_key | Lower-case match key; unique; may not equal any VRM `name_key` |
| alias_display | Spelling as entered |
| canonical_vrm_id | FK → VRMs.id |
| created_at, created_by | |

## ImportBatches (import register)
| Column | Description |
|---|---|
| id | Client-generated batch UUID |
| initiator_id | User id |
| file_name | Name only (≤120 chars); file content is never uploaded or stored |
| file_rows, client_rejected | Data rows in the file; rows rejected by browser checks (not sent) |
| mode | `structured` \| `list` |
| chunks_expected, chunks_committed | Parts planned; comma list of committed part indexes |
| received, accepted, duplicate_in_file, duplicate_existing, invalid, unauthorized, failed, created_vrms | Server outcome counters |
| started_at, finished_at, status | `in_progress` \| `completed` \| `cancelled` |

Reconciliation: `file_rows = client_rejected + received (+ rows never sent)`;
`received = accepted + duplicate_in_file + duplicate_existing + invalid + unauthorized + failed`.

## AuditEvents (append-only by the application)
| Column | Description |
|---|---|
| id, server_timestamp | UUID, UTC time |
| actor_user_id, actor_name, actor_role | From the session (empty for anonymous failed sign-in) |
| action | e.g. `login`, `addEntries`, `importChunk`, `correctEntry`, `softDeleteEntry`, `disableUser`, `exportReport` |
| entity_type, entity_id, vrm_id | Affected entity |
| before, after | JSON of changed fields (never passwords, tokens or code lists) |
| outcome | `success` \| `failure` \| `denied` \| `rejected` |
| request_id | Client request ID (or server request ID) |
| detail | Human summary (counts, reasons) |

## Sessions
| Column | Description |
|---|---|
| token_hash | SHA-256 of `session|token`; raw tokens are never stored |
| user_id, created_at, expires_at, last_seen_at, remember | |
| revoked_at, revoke_reason | `logout`, `password_changed`, `password_reset`, `role_changed`, `disabled` |

## ZeroReports
| Column | Description |
|---|---|
| id, vrm_id, business_date, actor_user_id, submitted_at | One active report per VRM and date |
| status, withdrawn_at, withdrawn_by | `active` \| `withdrawn` |

## IdempotencyRequests
| Column | Description |
|---|---|
| request_key, actor_user_id, action, created_at | Request identity |
| result | Stored JSON response (≤45,000 chars; otherwise summary only). Pruned after 14 days by `maintenance()` |

## Script Properties
`SPREADSHEET_ID` (required) · `PASSWORD_PEPPER` (generated by `setup()`; losing it invalidates all passwords) · `MEMBER_SCOPE`
(`team`|`own`) · `MEMBER_SEE_DUP_OWNER` · `PUBLIC_LOGIN_ROSTER` · `CODE_PATTERN` · `BACKUP_FOLDER_ID` · `BACKUP_RETENTION_DAYS`
· temporary `SETUP_NAME/SETUP_PASSWORD/SETUP_ROLE/SETUP_VRM` (deleted automatically by `provisionUserFromProperties()`).
